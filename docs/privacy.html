Void Terminal — Privacy Policy

Last updated: 2026-09-06

Void Terminal ("the app") is an SSH/local-shell terminal client for Android. This page explains what data the app handles and, just as importantly, what it does not.

Summary

Void Terminal has no backend server, no analytics, no ads, and no user accounts. Everything it stores lives only on your device. The only network connections it makes are the SSH connections you configure, directly to the host you specify.

What is stored, and where

  • Host list (addresses, usernames, ports, display names, per-host settings) — stored locally on-device using MMKV, plain local storage private to the app.
  • Passwords and the SSH private key — stored only in the Android Keystore, gated behind biometric authentication or your device passcode. They are never written to plain local storage, never logged, and never leave the device except as part of the SSH authentication handshake with the host you connect to.
  • Command history and app preferences (theme, font size, key-bar layout) — stored locally on-device using MMKV.

None of the above is transmitted to the developer or to any third party. There is no server operated by the developer that the app talks to.

Network access

The app opens a network connection only when you tap a saved host to connect — a direct SSH connection from your device to that host. No other network requests are made by the app itself.

Android permissions used

  • USE_BIOMETRIC / USE_FINGERPRINT — used to unlock saved passwords and your SSH private key before use. No biometric data is collected, stored, or transmitted by the app — authentication is handled entirely by the Android OS.
  • MANAGE_EXTERNAL_STORAGE — used only by the optional local-shell feature, so a local shell session can read/write your device's shared storage (Downloads, etc.) the same way a file manager or terminal app would. This permission is not required for the app's SSH functionality and is never requested unless you open the local-shell feature.

Third-party services

Void Terminal does not integrate any analytics, advertising, or crash-reporting SDKs, and does not share data with any third party.

Data deletion

All app data is stored locally. Uninstalling the app, or clearing its data/storage from Android's app settings, permanently deletes everything the app stored, including any saved passwords and keys in the Android Keystore.
