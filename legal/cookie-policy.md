## 1. Current Status

Void currently ships only as an Android application, distributed via
GitHub Releases and RuStore. There is no web version of Void.

The Android app does **not** use cookies, web storage, SDK-based
tracking identifiers, or any similar tracking technology. This document
is published now, ahead of any web version existing, purely to satisfy
app-store and legal-package completeness checklists that expect a
Cookie Policy to be present.

## 2. If a Web Version Is Released

If a web version of Void is released in the future, this policy will be
replaced with a complete Cookie Policy before that version becomes
publicly available, disclosing:

- Which cookies or similar technologies are used (strictly necessary,
  functional, analytics, or advertising);
- Their purpose and duration;
- Any third parties they belong to;
- How to manage or withdraw consent for non-essential cookies, as
  required under applicable law (e.g., the EU ePrivacy Directive /
  GDPR).

Until that happens, this section remains a placeholder and no cookie
consent mechanism exists because no cookies are set.
