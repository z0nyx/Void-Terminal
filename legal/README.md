## A note on scope

Void has no user accounts, no backend server, no analytics, no
advertising, and no third-party SDKs (no Firebase, no Discord OAuth, no
crash reporting). These documents are written to reflect that
accurately rather than to describe features the App doesn't have —
see the [Privacy Policy §3](./privacy.md#3-data-we-do-not-collect) for
an explicit list of what is *not* present.

## Not legal advice

These documents were prepared with AI assistance to be accurate,
complete, and consistent with how Void actually works, based on a
direct review of its source code. They are not a substitute for review
by a qualified lawyer, particularly if Void's feature set, data
handling, or distribution footprint changes materially in the future.
