MOBILE SSH · MOSH · TMUX · PKG
01 — THE PROBLEM

Every mobile terminal fails at the same place: the phone keyboard has no Ctrl, no Esc, no arrows, and one thumb has to reach everything. Output is dense and unscrollable, and a dropped connection loses the session.

02 — THE BETS
Paged key bar
Three rows — MOD, NAV, TMUX — one swipe or tap apart, sitting directly on the keyboard. Ctrl and Alt latch: tap once for one shot, twice to lock.
Ghost autocomplete
The rest of the command appears greyed ahead of the caret, from history and path. Tab or the ⇥ key accepts it, so long commands cost two taps.
Command rail
Every prompt leaves a tick on the right edge. Tapping a tick jumps to that command's output — scrollback without dragging through it.
Sessions survive
Mosh holds the session through the tunnel; the bar goes red and the buffer stays put instead of clearing.
03 — TRY IT

Tap a host to connect. In the session you can type on your real keyboard: ls uname -a pkg install neovim df -h tmux ls. Tab accepts the ghost, ↑ walks history.

In the session header, the bolt drops the link so you can watch mosh resume and the split square divides the pane. The command glyph at the end of the suggestion strip opens the snippet palette.
